🔹 1. Import Required Libraries
numpy → Used for numerical computations (arrays, matrices).

fetch_openml → Loads Boston Housing dataset from OpenML.

tensorflow / keras → Used to build and train Deep Neural Network.
🔹 2. Load Dataset
Dataset: Boston Housing Dataset
It contains information about housing prices in Boston suburbs.
Features (X):

Examples:

Crime rate
Number of rooms
Property tax rate
Distance to employment centers
Target (y):
House price (continuous value)

👉 This is a regression problem (predict continuous values).

🔹 4. Train-Test Split
train_test_split(test_size=0.2)
80% → Training data
20% → Testing data

👉 Why?

To evaluate model performance on unseen data.
🔹 5. Feature Scaling
StandardScaler()
Converts data into same scale (mean = 0, std = 1)

👉 Important because:

Neural networks perform better with normalized data
Prevents bias toward larger values
🔹 6. Build Neural Network
keras.Sequential([...])
Architecture:
Input Layer
Matches number of features
Hidden Layers
Dense(64, ReLU)
Dense(32, ReLU)
Dense(16, ReLU)

👉 ReLU = max(0, x) → introduces non-linearity

Output Layer
Dense(1) → single value (price)

👉 No activation because regression output is continuous.
