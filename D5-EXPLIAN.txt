🎯 📘 Viva / Practical Questions & Answers
🔹 Basic Questions
Q1. What is Fashion MNIST?

👉 Dataset of clothing images used for classification.

Q2. Problem type?

👉 Multi-class classification (10 classes)

Q3. Why reshape images?

👉 CNN requires 3D input (height, width, channel)

Q4. What is normalization?

👉 Scaling pixel values between 0 and 1

🔹 Intermediate Questions
Q5. What is convolution?

(I∗K)(x,y)=∑I(a,b)K(x−a,y−b)

Q6. Difference between MaxPooling and AvgPooling?
MaxPooling	AvgPooling
Takes max value	Takes average
Keeps strong features	Smoothens data
Q7. What is GlobalAveragePooling?

👉 Converts feature maps into single vector

Q8. What is softmax?

👉 Converts outputs into probabilities

🔹 Advanced Questions
Q9. Why CNN for images?

👉 Captures spatial patterns (edges, shapes)

Q10. What is overfitting?

👉 Model performs well on training but poorly on test

Q11. How to improve accuracy?
More epochs
Data augmentation
Add layers
Q12. Why use one-hot encoding?

👉 Required for multi-class classification

🔹 Output-Based Questions
Q13. What does confusion matrix show?

👉 Prediction accuracy per class

Q14. What is precision?

👉 Correct predictions / predicted positives

Q15. What is recall?

👉 Correct predictions / actual positives

Q16. What is F1-score?

👉 Balance between precision & recall
