🔹 2. Load Dataset
Dataset: Plant Disease Dataset (Augmented)

Structure:

👉 Each folder = one disease class

🔸 Steps Performed:
Read all folders (categories)
Assign label to each category
Load images using OpenCV
Resize images to 64×64
Limit images (200 per class) → avoids memory overflow
🔸 Normalization
data = data / 255.0

👉 Converts pixel values:

From 0–255 → 0–1

👉 Improves training stability

🔹 3. Train-Test Split
80% → Training
20% → Testing
🔸 One-Hot Encoding
to_categorical()

👉 Converts labels:

Class 2 → [0, 0, 1, 0, 0]

👉 Required for multi-class classification

🔹 4. Build CNN Model
Sequential()
🔸 CNN Architecture
🧩 1. Convolution Layer
Conv2D(32, (3,3), activation='relu')

👉 Extracts features (edges, textures)

Applies filters (kernels)
🧩 2. Pooling Layer
MaxPooling2D((2,2))

👉 Reduces image size

👉 Keeps important features

🧩 3. Second Conv + Pooling
More filters → deeper feature extraction
🧩 4. Flatten Layer
Flatten()

👉 Converts 2D image → 1D vector

🧩 5. Dense Layer
Dense(128, activation='relu')

👉 Learns complex patterns

🧩 6. Dropout Layer
Dropout(0.5)

👉 Randomly drops neurons

👉 Prevents overfitting

🧩 7. Output Layer
Dense(num_classes, activation='softmax')

🎯 📘 Viva / Practical Questions & Answers
🔹 Basic Questions
Q1. What is CNN?

👉 Neural network used for image processing.

Q2. What is plant disease detection?

👉 Classifying plant images into healthy or diseased categories.

Q3. Why resize images?

👉 To ensure fixed input size for CNN.

Q4. What is normalization?

👉 Scaling pixel values between 0 and 1.

🔹 Intermediate Questions
Q5. What is convolution?

👉 Operation to extract features:

(I∗K)(x,y)=∑I(a,b)K(x−a,y−b)

Q6. What is pooling?

👉 Reduces feature map size.

Q7. What is flattening?

👉 Converts 2D data into 1D vector.

Q8. Why use dropout?

👉 Prevents overfitting.

Q9. What is softmax?

👉 Converts outputs into probabilities.

🔹 Advanced Questions
Q10. Why CNN better than DNN for images?

👉 Captures spatial features (edges, patterns).

Q11. What is overfitting?

👉 Model memorizes training data.

Q12. How to improve accuracy?
More data
Data augmentation
Deeper network
Q13. What is filter/kernel?

👉 Small matrix used to extract features.

🔹 Output-Based Questions
Q14. What does confusion matrix show?

👉 Class-wise prediction performance.

Q15. What is precision?

👉 Correct positives / predicted positives

Q16. What is recall?

👉 Correct positives / actual positives

Q17. What is F1-score?

👉 Balance between precision & recall
